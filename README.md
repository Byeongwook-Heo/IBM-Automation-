## 브랜치 관리

`main`이 문서의 기준입니다. 기존 `codex/*` 브랜치는 문서 작성 이력으로 보존하며 별도 프로젝트로 취급하지 않습니다. `codex/add-installation-document-for-ibm-concert-60h96l`은 정리 전 `main`과 파일 내용이 동일했습니다.
